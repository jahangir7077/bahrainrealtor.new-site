## Status

The owner authorized development completion of the keyword and URL map on
2026-11-25. The source of record is
[`Bahrain_Property_Keyword_Master_PSEO.xlsx`](research/Bahrain_Property_Keyword_Master_PSEO.xlsx),

without sufficient verified inventory and unique, human-approved content.

same path below `/ar/` and require independently reviewed Arabic content.

`/buy-property/`. The general Bahrain real estate hub maps to `/`. Routes not
yet implemented must remain absent/404 and out of the sitemap.

## Ownership rules

- Each approved indexable URL has one primary intent and primary keyword;
  related terms may support that same page.
- Assign each primary keyword and distinct intent to one canonical URL. Do not
  create competing pages for keyword variations; review overlap before adding
  a page.
- Add a row only for a URL in the approved architecture. Record the language,
  intent, primary and supporting terms, evidence, and approval status before
  creating the page. Coordinate language variants with the approved URL plan.
- Validate terms against actual offerings, audience, language, and search
  evidence. Do not invent keyword metrics or promise rankings.
- Changes to URL or keyword ownership require owner approval and coordinated
  updates to this map and the architecture.
