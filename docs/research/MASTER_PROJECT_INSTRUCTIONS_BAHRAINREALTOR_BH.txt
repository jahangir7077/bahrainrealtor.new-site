## 5. Keyword mapping and cannibalization prevention

This is one of the highest-priority requirements.

Create a central keyword-to-URL mapping before writing content.

For every indexable URL, define:

- One primary keyword
- Supporting keywords
- Search intent
- Target audience
- Page type
- Proposed SEO title
- Meta description
- H1
- Internal linking targets
- Canonical URL
- Content differentiation
- Cannibalization risk

### Strict rules

- One primary search intent per indexable page.
- Similar keyword variations belong to the same page when intent is identical.
- Do not create multiple pages for singular/plural variations.
- Do not create separate pages for close synonyms.
- Do not create separate pages merely because a keyword has a slightly different word order.
- Do not assign the same primary keyword to competing URLs.
- Do not copy the same keyword-heavy introduction across multiple location pages.
- Do not create pages whose only difference is the area name.
- Do not create unnecessary overlapping FAQs or blog articles.

The main Buy Property page should target broad buying intent.

The main Rent Property page should target broad rental intent.

Each area-specific buying page should focus on property purchase intent in that area.

Each area-specific rental page should focus on rental intent in that area.

Individual project pages should focus on the specific development, its location, characteristics and available units.

Blog pages should answer informational questions rather than compete with transactional listing pages.

Residency pages should focus on visa eligibility and application information, not property-listing intent.

Where two existing pages compete for the same query, recommend consolidation, redirection or intent differentiation based on evidence.

Never merge URLs automatically.

### Keyword usage and content repetition

Use the primary keyword naturally in relevant locations, such as:

- SEO title
- H1
- Opening section
- Relevant subheadings
- Image alt text where descriptive
- Internal links where appropriate

Do not force the same exact phrase into every section.

Use meaningful synonyms, natural language, related entities and contextual terminology.

Avoid repetitive sentences, repeated introductions, boilerplate paragraphs, unnatural keyword density and excessive exact-match anchors.

Common grammatical words may naturally recur. The goal is not to eliminate ordinary repeated words, but to eliminate repetitive and unnatural content.

## 6. Original content and plagiarism standards

All website copy must be independently written.

Do not copy, spin, paraphrase sentence by sentence or imitate the structure of competitor pages.

Target less than 5% external text similarity where measured by a suitable plagiarism-checking service.

This is a target, not a guarantee. Similarity tools can produce false positives, especially for common industry terminology, names and factual statements.

For every important page:

- Research the topic.
- Identify what competitors are missing.
- Add original, useful information.
- Include Bahrain-specific context.
- Use verified facts.
- Add practical advice and examples where appropriate.
- Make the content genuinely useful to the reader.

Never fabricate first-hand experience, property transactions, testimonials or personal expertise.

Keep a record of authoritative sources for factual claims.
