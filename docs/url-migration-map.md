# Existing URL migration map

## Status

This is a same-domain rebuild on `https://bahrainrealtor.com/`. The existing
site's complete crawl, sitemap, analytics, Search Console data, backlinks and
language variants have not been supplied or audited in this repository. The
planned route inventory is not evidence that an existing URL does or does not
exist. Accordingly, no legacy URL is classified as retained, redirected, or
removed here, and no redirect is approved or active.

## Decision rules

- Retain useful URLs where appropriate, especially URLs with valuable content,
  backlinks or search visibility.
- Propose a permanent redirect only to a relevant, approved equivalent. Do not
  redirect unrelated pages to the homepage.
- Mark missing evidence and unresolved targets explicitly; do not infer them
  from the planned site architecture or provisional keyword map.
- Obtain owner approval before activating redirects or changing approved
  routes. Test status codes, chains, canonical URLs, language alternates and
  internal links before a separately approved cutover.
- Preserve the original inventory and evidence as source material.
