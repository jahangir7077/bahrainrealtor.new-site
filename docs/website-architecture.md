# Website architecture

## Status and scope

This is a proposed starting point, not an approved site structure. The repository
identifies the project as the new site for bahrainrealtor.com but contains no
approved sitemap, business requirements, or existing routes. A project owner
must approve the structure before design or implementation begins.

## Proposed URL inventory

| URL | Purpose | Status |
| --- | --- | --- |
| `/` | Introduce the Bahrain real estate site and guide visitors to its approved content. | Proposed; requires approval |

No other page, route, location, property category, language version, or
navigation item is approved yet. Do not treat this inventory as evidence that
the current live site has only one page.

## Change control

1. Agree on the audience, business goals, offerings, languages, and required
   pages with the project owner. Review the existing site and its URLs before
   planning a migration.
2. Record each approved page here with its URL, purpose, and approval status.
   Define its navigation and any relevant page relationships.
3. Assign its search intent and keywords in [keyword-map.md](keyword-map.md)
   and check it against [seo-strategy.md](seo-strategy.md).
4. Obtain explicit owner approval for changes to the architecture and keyword
   ownership before creating, removing, renaming, or redirecting pages.

If requirements are unclear or a requested page is absent from the approved
inventory, ask the owner rather than inventing a route or changing the strategy.
